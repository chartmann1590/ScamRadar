# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub private vulnerability reporting:

https://github.com/chartmann1590/ScamRadar/security/advisories/new

Include the affected area, reproduction steps, expected impact, and any relevant logs or screenshots. Do not publish exploit details publicly until a fix is available.

We will review reports as soon as possible, prioritize fixes based on severity and exploitability, and coordinate disclosure through the advisory thread.
